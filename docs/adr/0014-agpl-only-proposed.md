# ADR-0014: AGPL-3.0-only proposed licensing

Status: PROPOSED — legal review required

## Context and decision

The project is intended as Eduardo Miola's open-source IssueSpan project. AGPL-3.0-only is proposed to preserve source-sharing obligations for network use. This is not legal advice and is not final until reviewed and recorded by the project owner.

## Consequence

Repository headers, dependency compatibility, contribution terms, and hosted-service implications must be checked before release. No license claim in this ADR is production/legal approval.
